# 实验配置、指标与复现过程

本文档记录当前项目已经实现或正在实现的论文复现实验配置、评价指标和复现过程。后续上云训练前，优先按本文档检查数据、模型、指标和命令；已经跑过的训练现象统一记录在最后的“我们的复现过程”一栏。

## 0. 论文参数与当前复现配置总览

论文来源：

- arXiv: https://arxiv.org/abs/2105.14103
- Apple Machine Learning Research: https://machinelearning.apple.com/research/attention-free-transformer

本文档里的“论文参数”指论文 *An Attention Free Transformer* 第 5 节实验配置和对应表格。我们的实验是学习型复现，不是完全照搬论文训练工程。尤其是 CIFAR10 和 ImageNet，目前为了先确认代码、数据、DDP、AMP、checkpoint 和指标都能跑通，使用了缩小或保守配置。

### 三个实验的关键差异

| 实验 | 论文主配置 | 我们当前实际配置 | 当前结论 |
| --- | --- | --- | --- |
| Enwik8 | AFT-local-32，`T=1024`，论文表里包含 `L=12,d=512` 和 `L=24,d=256` 两组；batch 128，100 epochs，weight decay 0.5 | `L=24,d=256,T=1024,window=32`，2 卡，per-GPU batch 4，`grad_accum_steps=4`，effective batch 32，固定 lr `3e-4`，AMP + activation checkpointing | 能稳定训练，最好观察到 `val_bpc≈1.4974`，但不是论文完整训练协议 |
| CIFAR10 自回归 | AFT-local-256，factorized position bias rank 64，`seq_len=3071`；论文最好表格项是 `L=24,d=256`，test bpd 2.74；训练 200 epochs，batch 128，lr `3e-3`，weight decay 0.1，dropout 0.1 | `L=12,d=256,rank=64`，2 卡，per-GPU batch 1，`grad_accum_steps=8`，effective batch 16，lr `3e-4`，weight decay 0.01，5000 steps；已跑 `window=128` 和 `window=256` | `window128` 最好观察到 `val_bpd≈4.8875`；`window256` 最好约 `4.9979`，当前 reduced setting 下没有变好 |
| ImageNet-1K | ViT/DeiT 风格 patch16，crop 224；AFT-conv 去掉 class token 和绝对位置编码，用全局平均池化；tiny `L=12,d=192`，small `L=12,d=384`；主要 AFT-conv small `kernel=11/15,d=384`，top1 80.8/81.0 | 基线为 `L=12,d=256,kernel=3`；最新尝试为 `L=12,d=384,kernel=11,batch128,grad_clip=1,bias_limit=3`，2 卡，effective batch 256，lr `1e-4` | 最新配置截至 epoch 56 未再出现 NaN，最好 top1 63.468、top5 84.112，仍与论文有明显差距 |

### 不要混淆的几个点

- `batch_size` 在我们的 DDP 脚本里是每张 GPU 的 batch，不是总 batch。
- `effective_batch_size = batch_size * GPU数量 * grad_accum_steps`。
- `--use-checkpoint` 是 activation checkpointing，用来省显存；模型保存/恢复看 `--output-path`。
- CIFAR10 的 `step` 是 optimizer step；一个 step 内会跑 `grad_accum_steps` 个 micro batch。
- ImageNet 当前脚本默认按 epoch 打印日志，所以 `start epoch: 0` 后长时间不输出不一定是卡死。

## 1. Enwik8 字节级语言建模

### 数据集

Enwik8 是 Wikipedia 文本前 100,000,000 个 byte。我们采用 byte-level 建模：

```text
vocab_size = 256
原始序列长度 = 100,000,000
train.pt: [90,000,000]
val.pt:   [10,000,000]
```

训练 batch：

```text
x: [B, T]
y: [B, T]
```

其中 `y` 是 `x` 向后错一位：

```text
x = tokens[start : start + T]
y = tokens[start + 1 : start + T + 1]
```

### 模型

论文中 Enwik8 使用的关键变体是 AFT-local-32。表格里主要有两组 AFT-local-32：

```text
AFT-local-32, L=12, d=512, h=1, T=1024, test bpc=1.180
AFT-local-32, L=24, d=256, h=1, T=1024, test bpc=1.154
```

当前项目对应参数：

```text
--aft-type local
--local-window-size 32
--seq-len 1024
--n-layers 24
--d-model 256
--hidden-dim 1024
--causal
```

训练协议上，论文 Enwik8 说明为 batch size 128、100 epochs、weight decay 0.5，并使用与 CIFAR10 类似的 warmup 学习率计划。我们当前已跑通的 Enwik8 实验是旧版固定学习率配置，effective batch 为 32，没有完全复刻论文训练协议。

### 指标

训练代码直接计算的是 PyTorch 交叉熵：

```text
loss = CrossEntropyLoss(logits, targets)
```

这个 loss 使用自然对数，单位是 nats。论文 Enwik8 通常报告 BPC：

```text
BPC = loss / ln(2)
```

当前日志字段：

```text
step,train_loss,val_loss,val_bpc
```

### DDP 有效 batch

DDP 下：

```text
effective_batch_size = batch_size * world_size * grad_accum_steps
```

例如 2 卡：

```text
--batch-size 4
--grad-accum-steps 16
world_size = 2
effective_batch_size = 4 * 2 * 16 = 128
```

## 2. CIFAR10 自回归图像建模

### 数据集

CIFAR10 图像：

```text
train: 50,000 张
test:  10,000 张
image shape = [3, 32, 32]
```

自回归建模时，把图像展平成像素通道序列：

```text
3 * 32 * 32 = 3072
```

处理后：

```text
train.pt: [50,000, 3072]
test.pt:  [10,000, 3072]
```

训练 batch：

```text
sequences: [B, 3072]
x = sequences[:, :seq_len]
y = sequences[:, 1:seq_len + 1]
```

默认完整建模：

```text
seq_len = 3071
```

### 模型

论文 CIFAR10 自回归实验使用 AFT-local-256，并使用公式 7 的低秩位置偏置：

```text
任务: autoregressive density estimation
序列长度: seq_len = 3071
模型: AFT-local-256
位置偏置: factorized position bias, d0/rank = 64
论文表格主要配置:
  L=12, d=512, test bpd=2.80
  L=24, d=256, test bpd=2.74
训练设置:
  batch size = 128
  epochs = 200
  learning rate = 3e-3
  weight decay = 0.1
  dropout = 0.1
```

当前项目中，论文对应的结构参数是：

```text
--aft-type local
--local-window-size 256
--seq-len 3071
--use-low-rank-bias
--bias-rank 64
--causal 默认开启
```

但由于当前纯 PyTorch AFT-local 长序列实现训练成本较高，实际已完成的主实验不是这套完整论文配置，而是后面记录的 reduced setting。

### 指标

CIFAR10 自回归图像建模使用 BPD：

```text
BPD = loss / ln(2)
```

这里每个 dimension 是一个像素通道值，范围是 `0..255`。

当前日志字段：

```text
step,train_loss,val_loss,val_bpd
```

```bash

```


### CIFAR10 后续逼近论文配置的尝试顺序

1. 保持 `n_layers=12`，把 `local_window_size` 从 128 改回 256。

### 论文 ImageNet 配置

论文 ImageNet 实验是 AFT-conv 图像分类，整体沿用 ViT/DeiT 风格：

```text
dataset: ImageNet-1K
image_size: 224
patch_size: 16
num_classes: 1000
token pooling: global average pooling
class token: 不使用
absolute position embedding: 不使用
```

论文表格中的主要 AFT-conv 配置：

```text
AFT-conv tiny:
  L = 12
  d = 192
  kernel = 11
  top1 约 73.9/74.8

AFT-conv small:
  L = 12
  d = 384
  kernel = 11 或 15
  top1 约 80.8/81.0
```

其中 `kernel` 是 AFTConv2D 的局部卷积窗口大小，不是 patch size。patch size 仍然是 16。论文 small 级别更接近：

```text
--d-model 384
--hidden-dim 1536
--n-layers 12
--kernel-size 11
--image-size 224
--patch-size 16
```

### ImageNet 论文近似下一步命令

如果当前 `d=256,kernel=3` 训练结束后要更接近论文 small，可以尝试下面的结构。`batch_size` 可以根据显存从 64 逐步加到 128。针对上一次 epoch 14 的 NaN，当前命令额外启用 `--grad-clip 1.0`；代码中的 `position_bias` 约束上限为 `bias_limit=3.0`：

```bash
torchrun --nproc_per_node=2 scripts/train_imagenet_ddp.py \
    --data-dir /root/autodl-tmp/imagenet \
    --image-size 224 \
    --patch-size 16 \
    --num-classes 1000 \
    --d-model 384 \
    --hidden-dim 1536 \
    --n-layers 12 \
    --kernel-size 11 \
    --dropout 0.1 \
    --batch-size 128 \
    --epochs 90 \
    --learning-rate 1e-4 \
    --min-learning-rate 1e-5 \
    --warmup-epochs 5 \
    --weight-decay 0.05 \
    --num-workers 16 \
    --amp \
    --grad-clip 1.0 \
    --grad-accum-steps 1 \
    --eval-interval 1 \
    --save-interval 1 \
    --output-path outputs/aft_imagenet_small_k11_d384_b128_lr1e4_clip1_bias3.pt \
    --log-path outputs/aft_imagenet_small_k11_d384_b128_lr1e4_clip1_bias3_log.csv
```

注意这仍然不是论文完全训练菜谱，只是在模型结构上更接近论文 AFT-conv small。`kernel_size=11` 比 `kernel_size=3` 计算量大很多。必须使用新的输出路径，不能 resume 上一次已经出现 NaN 的 checkpoint。

### 4.2 CIFAR10 自回归复现过程

CIFAR10 自回归任务把每张图片展平成长度 3072 的 byte 序列，训练时使用 `seq_len=3071` 做 next-byte prediction。

实际过程中遇到几个主要问题：

#### 4.3.1 初始 ImageNet 问题

初始冒烟测试使用小 batch 时，`start epoch: 0` 后很久没有输出。原因是脚本按 epoch 打印日志，而 ImageNet 一个 epoch 很长，不是程序卡住。

之后尝试用更大 batch 换速度，曾经运行过 `batch_size=512, learning_rate=3e-4, AMP=True`。这组配置出现：

```text
train loss = nan
val loss = nan
top1 = 0.1
top5 = 0.5
```

判断为 AFTConv2D 中 `exp(k)` 在 AMP 下溢出，导致 `inf / inf -> nan`。后来在 `AFTConv2D` 里把 `k` 转成 float32，并沿 token 维减最大值：

```python
k_float = k.float()
v_float = v.float()
k_float = k_float - k_float.amax(dim=1, keepdim=True)
exp_k = torch.exp(k_float)
```

修复后，`d=256,kernel=3,batch128,lr1e-4` 稳定训练。
