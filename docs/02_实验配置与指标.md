# 实验配置与指标

本文档记录当前项目已经实现或正在实现的论文复现实验配置。后续上云训练前，优先按本文档检查数据、模型、指标和命令。

## 1. Enwik8 字节级语言建模

### 数据集

Enwik8 是 Wikipedia 文本前 100,000,000 个 byte。我们采用 byte-level 建模：

```text
vocab_size = 256
原始序列长度 = 100,000,000
train.pt: [90,000,000]
val.pt:   [10,000,000]
```

训练 batch：

```text
x: [B, T]
y: [B, T]
```

其中 `y` 是 `x` 向后错一位：

```text
x = tokens[start : start + T]
y = tokens[start + 1 : start + T + 1]
```

### 模型

论文中 Enwik8 使用的关键变体：

```text
AFT-local-32
T = 1024
L = 24
d = 256
```

当前项目对应参数：

```text
--aft-type local
--local-window-size 32
--seq-len 1024
--n-layers 24
--d-model 256
--hidden-dim 1024
--causal
```

### 指标

训练代码直接计算的是 PyTorch 交叉熵：

```text
loss = CrossEntropyLoss(logits, targets)
```

这个 loss 使用自然对数，单位是 nats。论文 Enwik8 通常报告 BPC：

```text
BPC = loss / ln(2)
```

当前日志字段：

```text
step,train_loss,val_loss,val_bpc
```

### DDP 有效 batch

DDP 下：

```text
effective_batch_size = batch_size * world_size * grad_accum_steps
```

例如 2 卡：

```text
--batch-size 4
--grad-accum-steps 16
world_size = 2
effective_batch_size = 4 * 2 * 16 = 128
```

### 2 卡 debug 命令

```bash
torchrun --nproc_per_node=2 scripts/train_enwik8_ddp.py --seq-len 1024 --batch-size 2 --grad-accum-steps 2 --d-model 256 --hidden-dim 1024 --n-layers 24 --dropout 0.1 --num-steps 20 --eval-interval 10 --save-interval 10 --learning-rate 3e-4 --aft-type local --local-window-size 32 --causal --amp --use-checkpoint --output-path outputs/ddp_debug_aft_local32_l24_d256_t1024.pt --log-path outputs/ddp_debug_aft_local32_l24_d256_t1024_log.csv
```

### 2 卡论文近似训练命令

```bash
torchrun --nproc_per_node=2 scripts/train_enwik8_ddp.py --seq-len 1024 --batch-size 4 --grad-accum-steps 16 --d-model 256 --hidden-dim 1024 --n-layers 24 --dropout 0.1 --num-steps 50000 --eval-interval 1000 --save-interval 2000 --learning-rate 3e-4 --aft-type local --local-window-size 32 --causal --amp --use-checkpoint --output-path outputs/aft_local32_l24_d256_t1024_ddp.pt --log-path outputs/aft_local32_l24_d256_t1024_ddp_log.csv
```

### 生成命令

```bash
python scripts/generate_enwik8.py --checkpoint outputs/aft_local32_l24_d256_t1024_ddp.pt --prompt "The " --num-new-tokens 500 --temperature 0.8 --top-k 40
```

## 2. CIFAR10 自回归图像建模

### 数据集

CIFAR10 图像：

```text
train: 50,000 张
test:  10,000 张
image shape = [3, 32, 32]
```

自回归建模时，把图像展平成像素通道序列：

```text
3 * 32 * 32 = 3072
```

处理后：

```text
train.pt: [50,000, 3072]
test.pt:  [10,000, 3072]
```

训练 batch：

```text
sequences: [B, 3072]
x = sequences[:, :seq_len]
y = sequences[:, 1:seq_len + 1]
```

默认完整建模：

```text
seq_len = 3071
```

### 模型

论文 CIFAR10 自回归实验使用 AFT-local-256。当前项目对应参数：

```text
--aft-type local
--local-window-size 256
--seq-len 3071
--causal 默认开启
```

### 指标

CIFAR10 自回归图像建模使用 BPD：

```text
BPD = loss / ln(2)
```

这里每个 dimension 是一个像素通道值，范围是 `0..255`。

当前日志字段：

```text
step,train_loss,val_loss,val_bpd
```

### 数据预处理

```bash
python scripts/prepare_cifar10.py
```

### 2 卡 debug 命令

```bash
torchrun --nproc_per_node=2 scripts/train_cifar10_ar_ddp.py --seq-len 512 --batch-size 1 --grad-accum-steps 1 --d-model 128 --hidden-dim 512 --n-layers 4 --dropout 0.1 --num-steps 20 --eval-interval 10 --save-interval 10 --learning-rate 3e-4 --aft-type local --local-window-size 64 --amp --use-checkpoint --output-path outputs/debug_cifar10_ar.pt --log-path outputs/debug_cifar10_ar_log.csv
```

### 2 卡论文近似训练命令

先从保守 batch 开始，确认显存后再上调：

```bash
torchrun --nproc_per_node=2 scripts/train_cifar10_ar_ddp.py --seq-len 3071 --batch-size 1 --grad-accum-steps 64 --d-model 256 --hidden-dim 1024 --n-layers 24 --dropout 0.1 --num-steps 50000 --eval-interval 1000 --save-interval 2000 --learning-rate 3e-4 --aft-type local --local-window-size 256 --amp --use-checkpoint --output-path outputs/aft_local256_cifar10_ar_ddp.pt --log-path outputs/aft_local256_cifar10_ar_ddp_log.csv
```

这条命令在 2 卡下的有效 batch：

```text
1 * 2 * 64 = 128
```

### 生成图片

```bash
python scripts/generate_cifar10_ar.py --checkpoint outputs/aft_local256_cifar10_ar_ddp.pt --output-image outputs/cifar10_generated.png --temperature 0.9 --top-k 50
```

## 3. 上云前检查

代码检查：

```bash
python -m compileall src scripts tests
pytest
```

数据检查：

```bash
ls -lh data/enwik8
ls -lh data/cifar10/processed
```

DDP 启动方式：

```bash
torchrun --nproc_per_node=<GPU数量> scripts/<训练脚本>.py ...
```

注意事项：

- 当前 DDP 脚本是单机多卡，不是多机多卡。
- `batch_size` 是每张 GPU 的 batch，不是总 batch。
- `effective_batch_size = batch_size * GPU数量 * grad_accum_steps`。
- Enwik8 指标看 `val_bpc`。
- CIFAR10 自回归指标看 `val_bpd`。
- 长训前必须先跑 debug 命令。
