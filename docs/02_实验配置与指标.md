# 实验配置与指标

本文档记录当前项目已经实现或正在实现的论文复现实验配置。后续上云训练前，优先按本文档检查数据、模型、指标和命令。

## 1. Enwik8 字节级语言建模

### 数据集

Enwik8 是 Wikipedia 文本前 100,000,000 个 byte。我们采用 byte-level 建模：

```text
vocab_size = 256
原始序列长度 = 100,000,000
train.pt: [90,000,000]
val.pt:   [10,000,000]
```

训练 batch：

```text
x: [B, T]
y: [B, T]
```

其中 `y` 是 `x` 向后错一位：

```text
x = tokens[start : start + T]
y = tokens[start + 1 : start + T + 1]
```

### 模型

论文中 Enwik8 使用的关键变体：

```text
AFT-local-32
T = 1024
L = 24
d = 256
```

当前项目对应参数：

```text
--aft-type local
--local-window-size 32
--seq-len 1024
--n-layers 24
--d-model 256
--hidden-dim 1024
--causal
```

### 指标

训练代码直接计算的是 PyTorch 交叉熵：

```text
loss = CrossEntropyLoss(logits, targets)
```

这个 loss 使用自然对数，单位是 nats。论文 Enwik8 通常报告 BPC：

```text
BPC = loss / ln(2)
```

当前日志字段：

```text
step,train_loss,val_loss,val_bpc
```

### DDP 有效 batch

DDP 下：

```text
effective_batch_size = batch_size * world_size * grad_accum_steps
```

例如 2 卡：

```text
--batch-size 4
--grad-accum-steps 16
world_size = 2
effective_batch_size = 4 * 2 * 16 = 128
```

### 已记录实验：老版 Enwik8 AFT-local 固定学习率

实验特征：

```text

位置偏置: 完整 [T, T] position_bias，不使用公式 7 低秩分解
学习率: 固定 learning_rate = 3e-4，不使用 warmup/cosine
seq_len: 1024
batch_size: 4 per GPU
GPU 数量: 2
grad_accum_steps: 4
effective_batch_size: 4 * 2 * 4 = 32
n_layers: 24
d_model: 256
hidden_dim: 1024
causal: True
AMP: True
activation checkpointing: True

```

## 2. CIFAR10 自回归图像建模

### 数据集

CIFAR10 图像：

```text
train: 50,000 张
test:  10,000 张
image shape = [3, 32, 32]
```

自回归建模时，把图像展平成像素通道序列：

```text
3 * 32 * 32 = 3072
```

处理后：

```text
train.pt: [50,000, 3072]
test.pt:  [10,000, 3072]
```

训练 batch：

```text
sequences: [B, 3072]
x = sequences[:, :seq_len]
y = sequences[:, 1:seq_len + 1]
```

默认完整建模：

```text
seq_len = 3071
```

### 模型

论文 CIFAR10 自回归实验使用 AFT-local-256。当前项目对应参数：

```text
--aft-type local
--local-window-size 256
--seq-len 3071
--causal 默认开启
```

### 指标

CIFAR10 自回归图像建模使用 BPD：

```text
BPD = loss / ln(2)
```

这里每个 dimension 是一个像素通道值，范围是 `0..255`。

当前日志字段：

```text
step,train_loss,val_loss,val_bpd
```

### 数据预处理

```bash
python scripts/prepare_cifar10.py
```

```text
1 * 2 * 64 = 128
```

### 当前可跑训练命令

完整 CIFAR10 自回归配置 `seq_len=3071, n_layers=24, local_window_size=256, grad_accum_steps=64, use_checkpoint=True` 在当前实现下过慢。实测 2 张 RTX 5090 上运行约 12 小时仍未到 `step 500`，虽然 GPU 利用率为 100%，但训练吞吐不适合继续烧云 GPU 时间。

当前使用的折中配置如下：

```bash
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True torchrun --nproc_per_node=2 scripts/train_cifar10_ar_ddp.py \
    --seq-len 3071 \
    --batch-size 1 \
    --grad-accum-steps 8 \
    --d-model 256 \
    --hidden-dim 1024 \
    --n-layers 12 \
    --dropout 0.1 \
    --num-steps 5000 \
    --eval-interval 100 \
    --save-interval 500 \
    --learning-rate 3e-4 \
    --min-learning-rate 1e-5 \
    --warmup-steps 200 \
    --weight-decay 0.01 \
    --aft-type local \
    --local-window-size 128 \
    --use-low-rank-bias \
    --bias-rank 64 \
    --amp \
    --output-path outputs/aft_cifar10_ar_t3071_w128_l12_d256_fast.pt \
    --log-path outputs/aft_cifar10_ar_t3071_w128_l12_d256_fast_log.csv
```

配置说明：

```text
seq_len = 3071: 仍然使用完整 CIFAR10 byte 序列建模。
n_layers = 12: 比 24 层配置减半，降低训练时间。
local_window_size = 128: 保留 AFT-local 局部位置偏置，但窗口从 256 降到 128。
grad_accum_steps = 8: effective_batch_size = 1 * 2 * 8 = 16。
use_checkpoint = False: 当前显存足够，不启用 activation checkpointing，避免 backward 重算 forward 拖慢速度。
eval_interval = 100: 每 100 个 optimizer step 评估一次，便于观察训练是否正常推进。
```

实测状态：

```text
GPU: 2 * RTX 5090 32GB
显存占用: 约 12.4GB / GPU
GPU 利用率: 约 83% 和 91%
现象: 5 分钟以内出现 step 100 日志，比完整 24 层、accum 64、checkpoint 配置明显更快。
```

截至 step 2900 的训练观察：

```text
step 0:    val_bpd = 8.2399
step 1000: val_bpd = 5.3632
step 2000: val_bpd = 5.3751
step 2300: val_bpd = 5.2011
step 2800: val_bpd = 5.1674
step 2900: val_bpd = 5.2980
```

该曲线说明模型可以正常学习，但在 step 2000 之后进入较明显的慢下降/震荡阶段。当前配置应记录为 `CIFAR10 自回归缩小配置实验`，不应写成论文表格级完全复现。

这条命令是当前用于获得可完成训练曲线的 CIFAR10 复现实验配置，不是论文表格指标复现配置。若要继续逼近论文配置，需要继续优化 AFT-local 的长序列实现。

## 3. 上云前检查

代码检查：

```bash
python -m compileall src scripts tests
pytest
```

数据检查：

```bash
ls -lh data/enwik8
ls -lh data/cifar10/processed
```

DDP 启动方式：

```bash
torchrun --nproc_per_node=<GPU数量> scripts/<训练脚本>.py ...
```

注意事项：

- 当前 DDP 脚本是单机多卡，不是多机多卡。
- `batch_size` 是每张 GPU 的 batch，不是总 batch。
- `effective_batch_size = batch_size * GPU数量 * grad_accum_steps`。
- Enwik8 指标看 `val_bpc`。
- CIFAR10 自回归指标看 `val_bpd`。
- 长训前必须先跑 debug 命令。
