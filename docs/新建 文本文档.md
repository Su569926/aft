  复现注意事项                                                                                                                                                  
                                                                                                                                                                
  最重要的是保留每次实验配置。每个 checkpoint 对应一个日志文件和命令，不要混用同一个 output-path，否则会自动 resume 旧实验。                                    
                                                                                                                                                                
  其次，正式训练前必须做冒烟测试。冒烟测试不是浪费钱，它是防止你一跑几个小时才发现数据路径、shape、DDP 同步或日志保存错了。                                     
                                                                                                                                                                
  还有，ImageNet 的 top-1/top-5 是论文图像分类实验核心指标。Enwik8 用 BPC，CIFAR10 自回归用 BPD，ImageNet 用 top-1/top-5 accuracy，不要用同一个指标评估所有实   
  验。                                                                                                                                                          
                                                                                                                                                                
  最后，云 GPU 时间贵，所以你现在的正确顺序是：                                                                                                                 
                                                                                                                                                                
  本地把代码写完整                                                                                                                                              
  本地 pytest 全部通过                                                                                                                                          
  云上先小步数冒烟测试                                                                                                                                          
  确认无误后再长训                                                                                                                                              
  每个实验单独保存 checkpoint 和 **log**
