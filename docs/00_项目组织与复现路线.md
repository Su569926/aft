# AFT 复现项目组织与实现路线

本文档是本项目的长期工作记忆：后续即使对话上下文被压缩，也优先以这里的约定为准。你负责亲手编码，我负责解释原理、审查实现、指出错误、安排下一步练习。

## 1. 当前复现目标

论文：*An Attention Free Transformer*，本地文件是 `2105.14103v2.pdf`。

建议的第一阶段目标：

1. 先复现 AFT-simple / AFT-full 中最核心的 AFT 层。
2. 用小张量做 shape test 和数值 sanity check。
3. 搭一个最小语言模型或分类模型，让 AFT block 真正参与训练。
4. 最后再考虑论文里的更多变体、完整实验和大数据集复现。

原因：你目前 PyTorch 和 Transformer 编码经验都少，直接追论文完整实验会被数据处理、训练工程和调参淹没。先把一个 AFT block 写对、跑通、能解释，是更稳的路径。

每个位置的职责：

- `src/aft/config.py`：保存模型配置，例如 `d_model`、层数、dropout、最大序列长度。
- `src/aft/layers.py`：实现最底层模块，例如 AFT 层、FeedForward、位置偏置。
- `src/aft/blocks.py`：把 AFT 层、LayerNorm、残差连接、FFN 组合成一个 block。
- `src/aft/model.py`：把 embedding、多个 block、输出头组合成完整模型。
- `tests/test_shapes.py`：先测试张量形状，再测试 mask、因果性、梯度是否存在。
- `scripts/train_toy.py`：最小训练脚本，不追求论文结果，只用于确认模型能训练。
- `configs/aft_toy.yaml`：保存 toy 训练参数，避免把所有超参数写死在脚本里。
- `data/`：放小数据集或下载后的数据。大文件不要提交到 git。
- `outputs/`：放日志、checkpoint、曲线图。实验产物不要和源码混在一起。
- `pyproject.toml`：让本项目能被 Python 识别为一个可导入包，后续测试可以稳定 `import aft`。
- `requirements.txt`：基础依赖清单，适合初学阶段直接安装。

## 3. 实现顺序

本项目建议从底向上实现，因为你需要建立 PyTorch 模块、张量形状和数学公式之间的对应关系。

### 第 0 步：环境和工具

目标：能导入 PyTorch、运行测试、执行训练脚本。

### 第 1 步：PyTorch 基础张量练习

目标：熟悉以下概念：

- `torch.tensor`、`torch.randn`
- 张量形状 `[batch, seq_len, d_model]`
- 广播 broadcasting
- `nn.Module`
- `forward`
- `loss.backward()`
- `optimizer.step()`

这一阶段不要急着写 AFT。先用非常小的线性层理解“前向、损失、反向、更新参数”。

### 第 2 步：实现 AFT 层

标准自注意力大致是：

```text
Q = X Wq
K = X Wk
V = X Wv
Attention(Q,K,V) = softmax(QK^T / sqrt(d)) V
```

AFT 的关键思想是：不显式计算每个 query 和 key 的点积相似度，而是用 key、value、位置偏置做加权聚合，再用 query gate 控制输出。

可先按论文核心形式理解：

```text
Y_t = sigmoid(Q_t) * weighted_average_over_positions(K, V, position_bias)
```

其中 `sigmoid(Q_t)` 是当前位置自己的门控，`weighted_average` 是所有位置的信息汇总。AFT 避免了标准 attention 中 `[seq_len, seq_len]` 的 QK 点积相似度矩阵，但某些变体仍可能有位置偏置矩阵。

第一版建议只写：

- 输入 `x`: `[B, T, D]`
- 输出 `y`: `[B, T, D]`
- 三个线性层：`to_q`、`to_k`、`to_v`
- 一个输出线性层：`out_proj`
- 可选 causal mask，先不加也可以

### 第 3 步：实现 FFN

FFN 是逐位置 MLP：

```text
FFN(x) = Linear(D, hidden) -> GELU/ReLU -> Dropout -> Linear(hidden, D)
```

注意：FFN 不混合不同 token，只在每个 token 的特征维度上变换。

### 第 4 步：实现 AFTBlock

采用 Pre-LN 结构：

```text
x = x + AFT(LayerNorm(x))
x = x + FFN(LayerNorm(x))
```

原因：

- LayerNorm 先归一化，训练更稳定。
- 残差连接让输入信息可以直接流过深层网络。
- 这和你笔记中的 Transformer 编码器层结构可以直接对应。

### 第 5 步：实现完整模型

最小语言模型结构：

```text
token_id -> token_embedding -> position_embedding -> AFT blocks -> LayerNorm -> lm_head -> logits
```

输入形状：

```text
input_ids: [B, T]
logits: [B, T, vocab_size]
```

### 第 6 步：写测试

先写这些测试：

1. AFT 层输入 `[2, 4, 8]`，输出必须是 `[2, 4, 8]`。
2. AFTBlock 输入输出形状一致。
3. 完整模型输出 `[B, T, vocab_size]`。
4. 做一次 loss.backward 后，关键参数的 `.grad` 不是 `None`。

测试优先级很高。对初学者来说，测试不是额外工作，而是帮你定位“张量形状到底哪里错了”的工具。

### 第 7 步：toy 训练

先用人工数据，例如“预测下一个数字”：

```text
输入:  0 1 2 3
目标:  1 2 3 4
```

如果 loss 能下降，说明模型、损失函数和优化器至少是连通的。

## 6. 先回答你笔记里的两个问题

### 三个模型全都要做吗？

不建议一开始全做。更合理的顺序是：

1. 先做最小 AFT 层，确认公式到代码无误。
2. 再做 AFT block 和 toy language model。
3. 如果前两步稳定，再补 AFT-full / AFT-local 等变体。
4. 最后才追论文实验。

复现论文不是一次性把所有变体抄完，而是逐层验证：公式正确、shape 正确、梯度正确、训练能下降、再扩大规模。

### 论文图 1 的注意力图是什么意思？

图里的“注意力图”通常是把不同位置之间的关联权重画成热力图。标准 Transformer 里可以直接画 `softmax(QK^T)`，因为它显式产生 `[T, T]` 的 token-to-token 权重矩阵。

AFT 的情况要更小心：AFT 不用标准的 query-key 点积注意力，所以不能简单说它有同样意义的 `QK^T` 注意力图。后续如果要复现图 1，我们需要先确认论文画的是哪一种权重：

- 标准 attention baseline 的注意力权重；
- AFT 中由 key、位置偏置、归一化项形成的有效权重；
- 或作者为了可视化额外定义的关联矩阵。

因此图 1 不急着做。等 AFT 层写完后，我们再专门做一个 `scripts/plot_weights.py` 或 notebook 来画热力图。

## 7. 学习记忆：后续指导约定

后续每次写代码时，都遵守这些原则：

1. 先写小模块，再写大模型。
2. 每个模块先确认输入输出 shape。
3. 每个重要张量都用 `[B, T, D]` 这种格式说明。
4. 不跳过 `nn.Module`、`forward`、`loss.backward()` 的解释。
5. 公式到代码的映射要逐行解释。
6. 优先写能跑通的小实验，再讨论论文完整指标。
7. 你自己写核心代码；我负责给步骤、解释、审查和纠错。
8. 如果上下文被压缩，继续以本文档为复现路线和教学约定。

## 8. 下一步建议

下一次可以从 `src/aft/layers.py` 开始。推荐先实现一个最小版本：

```python
class AFTSimple(nn.Module):
    def __init__(self, d_model: int, dropout: float = 0.0):
        ...

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        ...
```

你写完后，我会重点检查：

- `x`、`q`、`k`、`v` 的 shape 是否正确。
- softmax 或指数归一化的维度是否正确。
- 广播是否是你想要的广播。
- 输出是否仍是 `[B, T, D]`。
- 是否能反向传播。
